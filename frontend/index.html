The pipeline

Six agents, one auditable verdict

Four specialists each do one job and hand a structured result to the next. The other two exist to check them: one plans the run before it starts, one challenges the result before it is reported. Nothing is asserted that the system cannot show its working for.

Why it is built this way

Decision support, not a black box

01

Evidence you can check

Top-ranked variants with relevance scores, the criteria applied, and the ClinVar consensus behind the call — not a bare verdict.

02

Built for human oversight

Uncertain calls are labelled as such. Nothing reaches a report without a reviewer, date and signature, stored against the reviewing account.

03

The LLM is never the authority

Rules decide. Where LLM reasoning is enabled it works from the same retrieved evidence, and the reasoning mode used is recorded on every report.

04

Honest about its limits

Population-frequency evidence is flagged as limited. Decision support, never a diagnosis. Every result carries that framing.

Questions

Frequently asked

Does VariantLens diagnose anything?

No. It produces an algorithmic estimate from the evidence it can retrieve, which is decision support for a qualified professional. Every report states that it is not for standalone clinical use, and must be reviewed by a genetic counselor or clinical geneticist.

Which genes does it cover?

BRCA1 and BRCA2 only, which is where hereditary breast and ovarian cancer risk lives. The indexed extract holds 3,009 ClinVar records across the two genes. Other genes are out of scope for this prototype.

How does it decide how to search and how much to trust itself?

A supervisor agent plans each run from the parsed query: a named variant is retrieved narrowly and its classification must be justified by an exact match or a reviewed consensus, while a bare rsID or position is retrieved broadly and a partial match is tolerated instead. A verifier agent then checks the finished call against the evidence it rests on, and if the call claims more confidence than the evidence earns it is sent back once to be re-stated more conservatively. Both decisions are ordinary messages in the audit trail, so the reasoning behind a report is inspectable. Self-correction can only ever lower confidence — it can never manufacture certainty, and it never changes whether a variant is called pathogenic or uncertain.

What role does the language model play?

On the rule-based tier, none — classification is fully deterministic. Where LLM reasoning is enabled it reads the same retrieved evidence and produces a narrative, but the criteria and their outcomes are applied by code. The reasoning mode in use is recorded on every report.

What happens when ClinVar records disagree?

They are shown as disagreeing. A large share of the dataset carries conflicting interpretations, and collapsing those into a single number would misrepresent the underlying evidence.

Can I export or integrate the results?

Reports export to PDF, and the pipeline, evidence and audit trail are available as authenticated API endpoints. Both require the Professional tier or above.

Who can see my queries and sign-offs?

Queries, usage and review sign-offs are stored against your account. Administrators can see account-level usage and the upgrade queue, and every sign-off records the reviewing account and a timestamp.
