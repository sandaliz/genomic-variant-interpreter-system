# Analysis Results Directory

This directory contains the visualizations generated by `analysis.ipynb` for
presentation and evaluation purposes.

`analysis.ipynb` is a **production evaluation notebook**: it measures the deployed
4-agent system against real ClinVar labels. There is no separate machine-learning
model, so no ROC / feature-importance output is produced.

## Generated Visualizations

### Data Exploration
- **gene_distribution.png** — variants per BRCA1/BRCA2 gene and expert-agreement status
- **variant_types.png** — top 10 variant types in the dataset
- **impact_levels.png** — variant impact levels (HIGH, MODERATE, LOW, …)
- **allele_frequencies.png** — population allele-frequency distributions (ESP, ExAC, TGP)
- **cadd_scores.png** — CADD score distribution with the pathogenic threshold (20)

### Real Labels & System Evaluation
- **clinvar_classification_distribution.png** — real ClinVar `ClinicalSignificance` distribution
- **system_classification_results.png** — evidence-based vs consensus-reconciled accuracy
- **directional_agreement.png** — directional agreement (pathogenic / benign / uncertain)
- **predictor_completeness.png** — accuracy split by predictor completeness
- **confidence_distribution.png** — evidence-derived confidence score (0–100) distribution
- **clinvar_review_stars.png** — ClinVar review-star (0–3★) distribution
- **classification_performance.png** — per-class precision, recall, F1

### System Performance
- **ir_performance.png** — IR metrics: Precision@5, Recall@5, Exact-Match@5, MRR@5
- **system_architecture.png** — rubric-mapped 4-agent architecture diagram

## Regenerating Visualizations

```bash
source /Users/sandali/projects/.venv/bin/activate
jupyter notebook analysis.ipynb
# Run all cells (Cell → Run All) — figures are written to this directory
```

## Integration with Production System

The notebook calls `evaluation.py` directly, so the figures and the CLI evaluation
(`python3 evaluation.py --ground-truth real`) always report the same numbers.

## Note for Grading

- The production system (`main.py`, `api.py`) is the deployable artefact with text metrics
- The notebook mirrors its algorithms and renders the evidence for presentation
- Both share the same dataset, the same classifier and the same evaluation methodology
